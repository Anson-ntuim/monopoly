# 🎲 大富翁遊戲

一個用純前端技術打造的大富翁遊戲，包含股市系統和地產升級功能。

## ✨ 特色功能

- 🏠 **地產系統** - 購買地產、建造房屋和酒店
- 📈 **股市交易** - 即時股票交易系統，股價每回合波動
- 🎴 **機會與命運卡** - 隨機事件讓遊戲更刺激
- 👥 **2-4人遊戲** - 支援多人本地對戰
- 🎨 **簡約卡通風格** - 清爽的UI設計
- 💰 **完整遊戲規則** - 包含經典大富翁的所有基本規則

## 🚀 快速開始

### 安裝依賴
```bash
npm install
```

### 啟動開發伺服器
```bash
npm run dev
```

遊戲將在 `http://localhost:3000` 啟動

### 打包生產版本
```bash
npm run build
```

## 🎮 遊戲規則

1. **回合制** - 玩家輪流投擲骰子移動
2. **購買地產** - 踩到無主地產可以購買
3. **升級地產** - 擁有同色地產可以建造房屋/酒店
4. **支付租金** - 踩到他人地產需要支付租金
5. **股市交易** - 在股市交易所買賣股票
6. **機會命運** - 抽取卡片獲得獎勵或懲罰
7. **破產判定** - 現金不足時宣告破產
8. **勝利條件** - 最後存活的玩家獲勝

## 🛠️ 技術棧

- **TypeScript** - 類型安全的 JavaScript
- **Vite** - 快速的構建工具
- **HTML5 Canvas** - 遊戲渲染
- **純前端** - 無需後端服務器
